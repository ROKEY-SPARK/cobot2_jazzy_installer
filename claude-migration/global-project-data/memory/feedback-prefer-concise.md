학습용 문서 / Notion 페이지 / 설명 콘텐츠를 작성할 때 **concise (1 페이지 수준, 스캔 가능한 reference 카드 성격)** 를 기본으로 한다. 분량 많고 깊은(comprehensive) 출력은 피한다.

**Why:** Notion "(협동2) Humble→Jazzy 마이그레이션" Section 3 작성 시, 사용자가 깊이 선택지에서 "Comprehensive (Recommended)" 를 골랐으나 막상 plan 을 보고 "너무 분량이 방대하고 deep한데, 간략한 버전으로 다시" 라고 반려. 즉 더 무거운 옵션을 골랐어도 실제로 원하는 건 압축본이었음.

**How to apply:**
- 깊이/분량 선택지를 제시할 때 무거운 쪽 (comprehensive / 상세) 에 "Recommended" 라벨을 붙이지 말 것 — 그 라벨이 사용자를 잘못된 방향으로 nudge 했음.
- 표 5개 + 단락 10개 같은 구조보다 통합 표 1~2개 + 짧은 단락 + 압축 bullet 로. 각 항목 1~3줄.
- 단, 사용자가 명시적으로 "자세히 / 깊게 / comprehensive" 요청하면 그때는 상세 버전.
- 관련: 글로벌 output-style 의 "짧고 직접적, filler 금지" 와 일관.

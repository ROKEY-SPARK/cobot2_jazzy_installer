# Python 주석 작성 규칙

## 핵심 원칙

- **판단 기준**: 함수 시그니처(이름 + 타입 힌트)만 보고 쓸 수 있으면 간략히, 아니면 상세히
- **언어**: 설명문은 한국어 기본. 단, 아래는 영어 그대로 사용
  - Google Style 섹션 키워드 (`Args:`, `Returns:`, `Warning:` 등)
  - 코드 식별자, 타입명, 라이브러리/프레임워크 명칭, 토픽·메시지명
  - 한국어 정착 번역이 없는 기술 용어 (e.g. callback, publish, QoS)
  - → 핵심은 **한 문장 내 불필요한 영한 혼용 금지**
- **내용**: "무엇"보다 **"왜"** 를 우선 설명

---

## 표준 포맷 (Google Style 기반)

```python
def func(param: int) -> bool:
    """한 줄 요약 (동사로 시작, 마침표로 끝).

    [필요 시 상세 설명]

    Args:
        param (int): 설명. 단위·범위·기본값 포함.

    Returns:
        bool: 반환값 설명.

    Raises:
        ValueError: 발생 조건.

    Note:
        설계 의도, 알아두면 좋은 부가 정보.

    Warning:
        블로킹, 부작용, 스레드 안전성 등 주의사항.
    """
```

### 섹션 작성 기준

| 섹션 | 작성 조건 |
|---|---|
| 한 줄 요약 | 항상 필수 |
| `Args` | 파라미터가 있을 때 필수 |
| `Returns` | 반환값이 있을 때 필수 (None이면 생략) |
| `Raises` | 의도적으로 예외를 raise할 때 |
| `Note` / `Warning` | 해당 사항이 있을 때 |

## 클래스 추가 섹션 (ROS2 등 특수 케이스)

```python
class MyNode(Node):
    """노드 역할 한 줄 요약.

    Publishes:
        토픽명 (메시지타입): 설명. QoS 정보 포함.

    Parameters (로딩 시점·변경 가능 여부 명시):
        파라미터명 (타입): 설명. 기본값 포함.

    Warning:
        블로킹 동작, 런타임 제약 등.
    """
```

## 인라인 주석

- "왜"를 설명. 코드 번역 금지
- 태그: `# TODO:`, `# FIXME:`, `# NOTE:`

```python
# ❌ x = x * 0.98  # x에 0.98 곱하기
# ✅ x = x * 0.98  # 카메라 렌즈 왜곡 보정 계수
```
